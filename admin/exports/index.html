Export de la Base de Données Locale

Exportez les données modifiées sous forme de fichier JSON validé pour revue et intégration manuelle dans public/data/.

Mode navigateur : l'export lit uniquement le localStorage de ce navigateur. Le fichier téléchargé ne modifie pas le dépôt ni le site public. L'intégration doit être faite manuellement après revue.

Export complet

Cet export inclut toutes les collections de la base locale (produits, catégories, marques, fournisseurs, offres, historique des prix, vérifications de disponibilité, sources et résumé de recherche).

Limitations importantes

  • Les modifications administratives sont stockées uniquement dans ce navigateur.
  • Le fichier exporté est un téléchargement local — il ne publie pas le site.
  • Les données historiques (snapshot 2025-02-21) ne sont pas vérifiées de façon indépendante.
  • L'export valide la structure et les références, pas l'exactitude factuelle des prix.
