Intégration de Données

Spécification et Protocole d'Importation

Exigences techniques, schéma de validation et formats d'échange pour l'intégration de relevés en lot.

Pré-requis architectural : En l'absence d'une API d'écriture côté serveur, l'importation directe en base de données source requiert un script Node.js hors-ligne ou la mise à jour versionnée de public/data/*.json.

1. Format d'Échange Recommandé (JSON / CSV)

Les relevés de prix et fiches fournisseurs doivent respecter le schéma relationnel documenté dans public/data/schema.json.

Colonnes Obligatoires pour les Offres :

  • product_id : Identifiant valide existant dans products.json.
  • supplier_id : Identifiant valide existant dans suppliers.json.
  • price : Valeur numérique positive (en MAD).
  • availability_status : declared_available, in_stock, ou unknown.
  • verified_at : Date ISO-8601 (ex : 2025-02-15).
